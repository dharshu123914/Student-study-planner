# Student Study Planner

## Project Description
Student Study Planner is a web application
that helps students organize their academic activities.

## Problem Statement
Students sometimes find it difficult to manage
subjects, assignments, tasks and exam dates
in one place.

## Target Users
College students.

## Technologies Used
- HTML
- CSS
- JavaScript
- Local Storage

## Features
1. Student Dashboard
2. Subject Manager
3. Study Task Manager
4. Assignment Tracker
5. Daily Timetable
6. Exam Reminders
7. Study Progress Tracker

## Purpose
To help students organize their studies
and manage their academic activities easily.
